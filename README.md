# rent — бот поиска жилья (Хургада / Шарм-эль-Шейх)

Telegram-бот: собирает объявления из публичных Telegram-каналов, фильтрует
(аренда/покупка, город, цена в $/£/EGP, комнаты, давность) и присылает новые.

- Запуск: `pip install -r requirements.txt`, заполнить `.env` (см. `.env.example`), `python bot.py`
- Каналы: `/channels`, `/add имя [hrg|ssh]`, `/del имя`
- Секреты только в `.env` (не в git)
